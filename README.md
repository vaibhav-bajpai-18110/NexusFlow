
# NexusFlow
### Visual IoT Telemetry & Rule Engine

NexusFlow is a visual IoT telemetry monitoring and rule automation platform designed to collect, process, visualize, and analyze real-time device data.

## Project Objectives
- Collect telemetry data from IoT devices.
- Monitor device status and sensor readings in real time.
- Store and manage telemetry using MongoDB.
- Create visual automation rules using React Flow.
- Evaluate conditions using a rule engine.
- Display live updates through WebSockets.
- Provide an interactive monitoring dashboard.
