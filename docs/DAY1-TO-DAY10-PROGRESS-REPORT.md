## 1. Project Overview

NexusFlow is an IoT monitoring and rule-engine application designed to manage devices, process telemetry data, visualize real-time information, and evaluate rules for generating alerts.

The project combines a React-based frontend, a Node.js backend, and MongoDB for data storage.

## 2. Technology Stack

- Frontend: React, Vite, React Flow, Recharts
- Backend: Node.js, Express.js, WebSockets, RxJS
- Database: MongoDB, Mongoose
- Version Control: Git and GitHub
